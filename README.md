# Juegos

Menú para elegir juego, publicado en https://bayrontraderdeveloper.github.io/

- `index.html` página del menú · `lanzador.css` estilos · `lanzador.js` dibuja las tarjetas
- `juegos.js` lista de juegos: para añadir uno, copia un bloque y cambia nombre, texto, ruta, color y letra

Cada juego vive en su propio repo y se publica en `https://bayrontraderdeveloper.github.io/<repo>/`.
